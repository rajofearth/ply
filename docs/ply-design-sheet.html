Ply

Design Sheet — Visual Identity & System Reference
01 — Design Philosophy
Core Principles
Ply is a dense, dark-native desktop file explorer. Its visual language draws from the "Zeron" aesthetic — compact, achromatic, and utilitarian. Every design decision prioritises information density, fast scanning, and zero visual noise.
01
Zero-Hue Achromatic
The entire palette is greyscale. The only chromatic hue is destructive (red), reserved exclusively for Delete. Colour never communicates state — weight and contrast do.
02
Sharp Corners Everywhere
border-radius: 0 globally. The only exception is a 2px radius on media thumbnails in grid view. Ply rejects softness — it is precise, engineered, rectangular.
03
Native UI Font
No custom font is bundled. Ply uses the platform's native typeface — Segoe UI Variable on Windows, SF Pro on macOS, Ubuntu on Linux — for instant rendering and OS integration.
04
State via Weight, Not Colour
Active and selected states are communicated through font-weight: 500 (Medium) and background contrast shifts. Hue shifts are never used for interactive state.
05
Dense, Compact Layout
Row heights are 29px. Titlebar is 38px. Status bar is 26px. Every pixel is budgeted for maximum information density. Ply fits more on screen than any competitor.
06
OKLCH-Authored, sRGB-Delivered
Tokens are authored in OKLCH (the perceptually uniform space behind shadcn/ui) and pre-converted to sRGB hex values for rendering. The OKLCH source is recorded alongside each value for provenance.

03 — Typography
Type Scale
Ply uses the platform's native UI font. No custom typeface is bundled. The scale is tight and purpose-built for dense information display.

macOS: .SystemUIFont → SF Pro Text → Helvetica Neue → Arial
Linux: Ubuntu → Roboto → DejaVu Sans → Helvetica → Arial

04 — Iconography
Lucide Icons (v1.31.0)
All icons are vendored Lucide SVGs with stroke="currentColor". They are tinted at render time via the text color. No dependency on gpui-component's icon pack. Stroke width: 1.5px. Line cap & join: round.
