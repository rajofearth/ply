# Enumerate Current Folder; do not index the machine

Zed keeps a scanned worktree SumTree so search and git can run. An explorer stays fast by listing only the folder you are looking at. Ply is an explorer: sidebar branches load their subfolders only when expanded, and the centre pane holds a Vec of Current Folder Entries. We never background-index a drive. The watch covers Current Folder only, debounces, ignores access/atime events (reading a folder would otherwise retrigger itself forever), and skips `cx.notify()` when the Snapshot fingerprint is unchanged. Directory IO and volume discovery run off the UI thread — enumerating volumes can block on an unreachable network share.
